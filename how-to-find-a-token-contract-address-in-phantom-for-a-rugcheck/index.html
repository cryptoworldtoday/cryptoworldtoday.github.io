How to find a token contract address in Phantom for a rugcheck

To find a Solana token contract address in Phantom, open the token and copy its mint address; verify it in Solscan before using it for a risk check.

By The Coin Wire EditorialNov 25, 2026 · 21:51 UTC5 min read

Open the token in Phantom and copy its mint address from the token details. On Solana, that mint address is what people mean by a token’s “contract address,” “CA” or “token address.”

That distinction matters when you’re preparing a rugcheck: the check needs the token’s mint, not the separate address for your personal token account. Start with Phantom open on the wallet holding the token, and make sure the token appears in its token list.

The mint identifies the token; your token account holds your balance

The mint address identifies a Solana token. It is a base58 public key for the token’s mint account, and explorers and token lookup tools use it to identify which asset you mean.

Your balance sits in a different account. Solana creates an associated token account for a wallet and a particular mint; that address is derived from both. A wallet can therefore have a token account for a mint, but the token account is not the mint itself.

This difference can be easy to miss in Solscan. On your wallet’s page, a token row or transfer detail may show the associated token account address. Pasting that address into a rugcheck lookup can return no token, because the lookup expects the mint. Copy the field labeled “Mint” or “Contract address” instead.

Phantom’s current instructions place the address in the token detail view: mobile shows it under “About” the token, while the browser extension shows “Info.” The labels can vary with the view, but look for the mint or contract address field. Phantom’s token address instructions cover both layouts.

Copy the address from Phantom, then verify it in Solscan

With the correct wallet open and the token visible, copy the address from its detail page. Use this short sequence to leave with the mint ready for a lookup:

  1. Tap or click the token in Phantom’s token list. This opens that token’s detail view, rather than the general wallet view.
  2. Open the token information section. On mobile, look under “About”; in the extension, look under “Info.” You should see a field labeled “Mint” or “Contract address.”
  3. Copy that field’s value. The result should be a long base58 address, not your Phantom wallet address or the address of your associated token account.
  4. Paste the copied value into Solscan’s search. Confirm it opens a token page with the name and supply you expect, rather than an account page for your wallet or a token account.
  5. Paste the same mint into the rugcheck lookup. The result is now tied to the token identified by that mint.

Say you hold a token called Northstar and want to inspect it. You open Northstar in Phantom, then copy the mint shown in its information section. In Solscan, that address opens Northstar’s token page and shows the expected name and supply. You now have the token identifier needed for a rugcheck, rather than an address tied only to your wallet’s balance.

Solscan is useful here as a confirmation step: it lets you see whether the copied value resolves to a token page with the details you recognize. Names and symbols can be shared by different tokens, so a familiar label alone is a weaker check than the mint. Compare the mint with the project’s official site or other official channels before treating it as the project’s real token.

If the token detail view does not expose the mint, use its receive transaction as a fallback. In Phantom, open Activity and select the transaction that brought the token into the wallet. View that transaction on Solscan, then find the token transfer line and copy the mint shown there. Check that it opens the expected token page; do not copy the “To” address if it identifies your token account.

The common wrong turn is copying an address from your Solscan wallet page just because it appears next to the token. That may be the associated token account holding your balance. The two addresses refer to different things: one identifies the token; the other identifies your wallet’s account for holding that token. When a lookup finds no token, return to Phantom and copy the mint field.

How do I confirm the mint address is the project's real token?

Compare the mint from Phantom with the address published by the project through an official website or account. Then check that Solscan’s token page shows the expected name and supply. A matching name or logo by itself is not enough to distinguish tokens that use similar branding.

How do I hide spam tokens in Phantom?

Use Phantom’s token controls to hide a token you do not recognize, and avoid links or claim instructions attached to it. A token appearing in the wallet does not establish that it is the project’s real token. Find the mint only if you need to identify it, and verify it against a source you trust.

Once Solscan shows the expected token page, keep that mint as your reference and review the rugcheck result before interacting with the token. That gives you a chance to investigate any warnings while you are still deciding what to do.
