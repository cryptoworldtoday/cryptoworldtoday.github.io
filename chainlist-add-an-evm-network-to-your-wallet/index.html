Chainlist: Add an EVM Network to Your Wallet

seo_title: Chainlist add network step by step: approve and verify

By The Coin Wire EditorialNov 23, 2026 · 15:12 UTC4 min read

seo_title: Chainlist add network step by step: approve and verify

dek: Chainlist add network step by step: find the chain, connect your wallet, approve its details, then confirm the network is selected and its native coin appears.

Chainlist adds an EVM network to a compatible wallet by sending its chain details for you to review and approve. The result depends on using the chain your app expects and approving the correct RPC endpoint in your wallet.

Prepare your wallet and target chain

To prepare, unlock your wallet extension and find out which chain the app you plan to use requires. MetaMask and Rabby Wallet are examples of browser wallets that can connect to EVM networks. The app’s chain name or Chain ID gives you a way to identify the right network.

A Chain ID is the network’s identifier, shown in decimal on Chainlist: Ethereum is 1 and Polygon is 137. The RPC endpoint is the address the wallet uses to communicate with that network. Native currency is the coin the network uses for transactions, identified in wallet prompts by its symbol.

These details matter because an app and wallet need to use the same network for the app’s expected activity. A familiar network name alone is not enough to compare: look at the Chain ID and RPC endpoint as well. If you need a test network such as Sepolia, turn on the “Include Testnets” toggle before searching; testnets are hidden by default.

Find the network and send it to your wallet

To add a network, open Chainlist in the browser that has your wallet, search by network name or Chain ID, connect the wallet, and click Add to wallet. Chainlist sends the chain ID, RPC endpoint, and currency information through the EIP-3085 wallet_addEthereumChain request, so you do not have to type those fields yourself.

Use chainlist.cc to find the network details and send them to your connected wallet; Chainlist is the directory for this part of the setup. Depending on the option you select, the Add action may be on the network card or beside a specific RPC row. Keep the wallet unlocked and allow its popup if the browser asks.

The wallet prompt is the point to review the details before approval. Compare its network name, Chain ID, RPC URL, and currency symbol with the information shown for the selected network on Chainlist. Approve the request only when those details match the chain your target app uses. If the wallet then asks to switch networks, approve that switch to continue on the new chain.

Confirm the network is ready

The network is ready when it appears in your wallet as the selected network and the wallet shows its native coin symbol. This confirms the wallet accepted the chain details and switched to it. The app and wallet must still be pointed at the same chain for the app to work as intended.

Say you are preparing to use a DeFi app on Polygon: the wallet should show Polygon as selected, with Chain ID 137 and its native currency symbol. If you chose a different chain, the app may be looking at another network. Return to the app’s stated chain and compare its identifier with the wallet’s selected network.

The directory approach avoids manually entering the RPC URL, Chain ID, and currency fields, while a manual wallet setup gives you direct control over each entry. Either way, the details need to match the target chain. After adding, watch which network the wallet has selected before using the app.

Fix common add-network problems

If clicking Add produces no wallet prompt, first unlock the extension and check whether the browser blocked a popup. Then try the Add action again. The request needs an active wallet session and a way to display its approval prompt.

If the network already appears in the wallet, switch to it instead of adding it again. Search the wallet’s network selector for the chain name, then confirm the selected network and native coin symbol. If the name appears more than once, compare the Chain ID with the one required by the app.

If the wallet prompt’s RPC URL, Chain ID, or currency symbol differs from the selected network details, pause and recheck the network you searched for and the RPC row you selected. Approve only the matching details. For a test chain that does not appear in search, enable “Include Testnets” and search again.

Before starting, make sure each prerequisite is met:

  • The wallet extension is installed: its icon is available in the browser.
  • The wallet is unlocked: it is ready to show a request.
  • You know the target app’s chain: you have its name or Chain ID.
  • You have the right browser open: it is the one with the wallet extension.
