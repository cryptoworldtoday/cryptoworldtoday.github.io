Uniswap v4 adds outside liquidity on three chains

Uniswap’s v4 hooks add seven outside liquidity sources across three chains, widening route choice while charging protocol fees on external trades.

By The Coin Wire EditorialOct 25, 2026 · 10:58 UTC3 min read

Uniswap Labs launched Aggregator Hooks on October 22 in its web app and API for Ethereum mainnet, Base and Robinhood Chain, letting Uniswap v4 route swaps through liquidity held on other platforms. The company says seven sources are available at launch, covering more than 90% of DEX activity across those chains. In its launch announcement, Uniswap said trades routed through the outside sources will pay protocol fees that contribute to UNI burns.

How do the hooks change Uniswap’s routing?

Each hook presents an external liquidity source to a router as if it were a Uniswap v4 pool. Uniswap says the router refreshes quotes from connected sources every block, then builds a route across native Uniswap pools and external venues; the full route settles in one transaction, with no new approval required. In the web app, outside liquidity is included automatically. Developers can access the feature through the API.

Before this rollout, v4 routing could use its own pools, while this feature extends the set of venues it can consider without sending users to a separate interface. That gives the router more possible sources for a trade, but a wider set alone does not establish that every swap will get a better price. The result depends on the available quotes and the route chosen for each trade.

Uniswap named Fluid, Curve and PancakeSwap among the launch sources, according to The Block’s report on the rollout. The seven-source total and 90% coverage figure come from Uniswap; the announcement does not list all seven sources or explain how it calculates that coverage.

What is different from the earlier rollout?

The launch expands both the chain coverage and the access route. The Block reported that the first aggregator hook went live on Tempo in March 2026, but that chain was supported through the web app only. Ethereum, Base and Robinhood Chain are supported through both the app and API. The rollout also follows Uniswap’s November 2025 UNIfication proposal, which The Block says first set out plans for aggregator hooks.

The move changes how Uniswap can capture value from trading activity outside its own pools. Uniswap says it has processed more than $4.5 trillion in total trading volume and that most onchain liquidity is already on its platform. Hooks extend its reach to liquidity that forms elsewhere, while protocol fees on swaps using those sources create a fee stream tied to external venues. Those fees are intended to contribute to UNI burns; neither source reports how much the new routing has generated or burned.

What should traders and builders watch next?

The next measures are how many of the seven sources see actual routed volume, whether the feature reaches additional chains, and how fees and UNI burns develop as usage accumulates. For traders, the practical comparison is the execution route and resulting trade terms, not simply the number of venues connected. For API developers, the addition means external liquidity can be considered through Uniswap’s existing routing interface on three networks.

The design bundles route discovery into Uniswap’s app and API, but the available evidence so far describes the launch rather than its performance. Uniswap has not published route-by-route execution comparisons or usage figures for Aggregator Hooks. Those data will show whether the broader routing set changes where trades execute, and how much activity shifts from native pools to outside sources.
